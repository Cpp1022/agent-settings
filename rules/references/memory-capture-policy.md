# Memory Rules

## What To Store

Only store durable and reusable info:

- PROJECT_STATE: current stage, next steps, blockers
- DECISIONS: chosen option and reason
- EXPERIMENTS: idea result and evidence

## What Not To Store

- Verbose chat transcript
- Temporary guesses without decision
- Duplicate information already in rules/plans

## Write Format

Each entry should be short:

- 3-6 lines per item
- include date and owner
- include next action

## Update Timing

- End of each non-trivial task
- Before context handoff / session end
